# 📚 Apuntes y Guías de Estudio - Matemáticas Discretas

Repositorio con apuntes, talleres prácticos y diccionarios de símbolos para la asignatura de **Matemáticas Discretas**. Cada tema cuenta con su archivo de lectura en texto plano (`.txt`) y su versión tipográfica lista para imprimir o leer en digital (`.pdf`).

---

## 📂 Contenido del Repositorio

| Tema / Documento | Versión Texto | Versión PDF | Descripción |
| :--- | :---: | :---: | :--- |
| **01. Conjuntos** | [`01_conjuntos.txt`](./01_conjuntos.txt) | [`01_conjuntos.pdf`](./01_conjuntos.pdf) | Guía teórica completa: Pertenencia ($\in$) vs Inclusión ($\subseteq$), conjuntos por comprensión y extensión, y ejercicios resueltos paso a paso. |
| **02. Regla de Cramer** | [`02_regla_de_cramer.txt`](./02_regla_de_cramer.txt) | [`02_regla_de_cramer.pdf`](./02_regla_de_cramer.pdf) | Solución de sistemas de ecuaciones lineales $3 \times 3$ mediante determinantes (Método de Sarrus), comprobaciones y trampas típicas de examen. |
| **Diccionario de Símbolos** | [`diccionario_simbolos.txt`](./diccionario_simbolos.txt) | [`diccionario_simbolos.pdf`](./diccionario_simbolos.pdf) | Glosario de consulta rápida: definición, forma de uso, ejemplos y advertencias para cada símbolo matemático. |
| **Taller 01: Ejercicios** | [`taller_01_conjuntos_ejercicios.txt`](./taller_01_conjuntos_ejercicios.txt) | [`taller_01_conjuntos_ejercicios.pdf`](./taller_01_conjuntos_ejercicios.pdf) | Taller de práctica para resolver a mano con ejercicios de pertenencia, inclusión y conversión entre comprensión y extensión. |

---

## 🎯 Organización

- Los archivos `.txt` están redactados de corrido para fácil lectura en cualquier editor o terminal.
- Los archivos `.pdf` cuentan con formato limpio, tipografía legible y bloques destacados para fórmulas, matrices y advertencias de examen.
