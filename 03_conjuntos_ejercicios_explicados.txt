========================================================================
BLOQUE 1: LOS 12 REACTIVOS CRITICOS DE PERTENENCIA (∈) E INCLUSION (⊆)
========================================================================

1. ALGORITMO DE EVALUACION RAPIDA:
- Pertenencia (x ∈ M): Abres M. ¿Esta el elemento x exactamente igual 
  a como esta escrito (con o sin llaves)? Si si -> V. Si no -> F.
- Inclusion (X ⊆ M):
  * ¿Es ∅ ⊆ M? -> V SIEMPRE (axioma universal).
  * ¿Tiene llaves exteriores? Si no tiene llaves -> F INMEDIATO.
  * Destapa las llaves exteriores: Comprueba si cada elemento interno 
    pertenece a M. Si todos estan -> V. Si falta uno -> F.


2. EJEMPLO MODELO: CONJUNTO M = { 3, {3}, {4}, ∅ }
Elementos: 3, {3}, {4}, ∅.

1.  3 ∈ M      -> V (El 3 suelto esta en la lista).
2.  {3} ∈ M    -> V (El objeto {3} es el 2.° elemento).
3.  3 ⊆ M      -> F (No tiene llaves; elemento no incluye).
4.  {3} ⊆ M    -> V (Destapamos {3} -> 3. Como 3 ∈ M -> V).
5.  {{3}} ⊆ M  -> V (Destapamos {{3}} -> {3}. Como {3} ∈ M -> V).
6.  4 ∈ M      -> F (Trampa: en M esta {4}, pero el 4 suelto no).
7.  {4} ∈ M    -> V (El objeto {4} es el 3.° elemento).
8.  {4} ⊆ M    -> F (Destapamos {4} -> 4. Pero 4 ∉ M -> F).
9.  {{4}} ⊆ M  -> V (Destapamos {{4}} -> {4}. Como {4} ∈ M -> V).
10. ∅ ∈ M      -> V (Esta explico en la lista).
11. ∅ ⊆ M      -> V (Regla universal del vacio).
12. {∅} ⊆ M    -> V (Destapamos {∅} -> ∅. Como ∅ ∈ M -> V).


3. TU TURNO: EJERCICIO ESPEJO 1
Dado el conjunto: W = { 5, {5}, {1, 2}, ∅ }
Determina si cada una es V o F:
1.  5 ∈ W
2.  {5} ∈ W
3.  5 ⊆ W
4.  {5} ⊆ W
5.  {{5}} ⊆ W
6.  1 ∈ W
7.  {1, 2} ∈ W
8.  {1, 2} ⊆ W
9.  {{1, 2}} ⊆ W
10. ∅ ∈ W
11. ∅ ⊆ W
12. {∅} ⊆ W

------------------------------------------------------------------------
[SOLUCION Y CHECKPOINT DEL EJERCICIO ESPEJO 1]
------------------------------------------------------------------------
1.  5 ∈ W         -> V (El 5 suelto es el 1.° elemento).
2.  {5} ∈ W       -> V (El objeto {5} es el 2.° elemento).
3.  5 ⊆ W         -> F (Sin llaves exteriores).
4.  {5} ⊆ W       -> V (Destapamos {5} -> 5. Como 5 ∈ W -> V).
5.  {{5}} ⊆ W     -> V (Destapamos {{5}} -> {5}. Como {5} ∈ W -> V).
6.  1 ∈ W         -> F (Trampa: en W esta {1, 2}, el 1 suelto no).
7.  {1, 2} ∈ W    -> V (El paquete {1, 2} es el 3.° elemento).
8.  {1, 2} ⊆ W    -> F (Destapamos -> 1 y 2. Ninguno esta suelto en W).
9.  {{1, 2}} ⊆ W  -> V (Destapamos -> {1, 2}. Como {1, 2} ∈ W -> V).
10. ∅ ∈ W         -> V (El simbolo ∅ esta explico en W).
11. ∅ ⊆ W         -> V (Regla universal del vacio).
12. {∅} ⊆ W       -> V (Destapamos -> ∅. Como ∅ ∈ W -> V).


========================================================================
BLOQUE 2: COMPRENSION A EXTENSION CON RESTRICCIONES CRITICAS
========================================================================

1. ALGORITMO:
- Resolver algebra.
- Filtrar por universo (N: solo naturales positivos; Z: positivos, negativos, cero).
- Conectar (v: unimos; ^: intersectamos).

2. EJEMPLOS MODELO:
- A = { x ∈ N / x^2 - 2x - 8 = 0 }  -> A = { 4 } (Se descarta -2 en N).
- B = { x / x letra de "universidad" } -> B = { a, d, e, i, n, r, s, u, v }
- C = { x ∈ Z / x^2 - 16 = 0 v 3x + 2 = -7 } -> C = { -4, -3, 4 }
- D = { x ∈ Z / -3 <= x < 3 } -> D = { -3, -2, -1, 0, 1, 2 }
- E = { x ∈ Z / |x - 1| <= 2 } -> E = { -1, 0, 1, 2, 3 }

3. TU TURNO: EJERCICIO ESPEJO 2
Determina por extension:
1. A2 = { x ∈ N / x^2 - 3x - 10 = 0 }
2. B2 = { x / x letra de "probabilidad" }
3. C2 = { x ∈ Z / x^2 - 36 = 0 v 2x + 5 = -1 }
4. D2 = { x ∈ Z / -4 < x <= 2 }
5. E2 = { x ∈ Z / |x + 1| <= 3 }

[SOLUCION Y CHECKPOINT DEL EJERCICIO ESPEJO 2]
------------------------------------------------------------------------

2. B2 = { a, b, d, i, l, o, p, r }

========================================================================
BLOQUE 3: EXTENSION A COMPRENSION (FORMULAS Y SUCESIONES)
========================================================================

1. ALGORITMO:
- Diferencia constante: d*k + c.
- Multiplos infinitos en ambos lados: m*k con k ∈ Z.
- Crecimiento acelerado: k^2, k^3, 2^k.

2. EJEMPLOS MODELO:
- F = { 5, 10, 15, 20, 25, 30 }       -> { 5k / k ∈ N, 1 <= k <= 6 }
- G = { 1, 8, 27, 64, 125 }           -> { k^3 / k ∈ N, 1 <= k <= 5 }
- H = { ..., -8, -4, 0, 4, 8, ... }   -> { 4k / k ∈ Z }
- I = { 2, 4, 8, 16, 32, 64 }         -> { 2^k / k ∈ N, 1 <= k <= 6 }
- J = { 4, 7, 10, 13, 16 }            -> { 3k + 1 / k ∈ N, 1 <= k <= 5 }

========================================================================
BLOQUE 4: LAS 10 OPERACIONES FUNDAMENTALES CON UNIVERSALES
========================================================================

1. EJEMPLO MODELO:
U = { 1 .. 10 }
A = { 1, 2, 3, 5, 7 }
B = { 2, 4, 6, 7, 8 }
C = { 3, 5, 7, 9, 10 }

Resultados:
1. A U B = { 1, 2, 3, 4, 5, 6, 7, 8 }
2. A ∩ B = { 2, 7 }
3. A - B = { 1, 3, 5 }
4. B - A = { 4, 6, 8 }
5. A' = { 4, 6, 8, 9, 10 }
6. A Δ B = { 1, 3, 4, 5, 6, 8 }
7. (A U B) ∩ C = { 3, 5, 7 }
8. A - (B ∩ C) = { 1, 2, 3, 5 }
9. (A ∩ B)' = { 1, 3, 4, 5, 6, 8, 9, 10 }
10. (A - C) U (B - C) = { 1, 2, 4, 6, 8 }


2. TU TURNO: EJERCICIO ESPEJO 4

P = { 2, 3, 5, 7 }
Q = { 1, 3, 5, 7, 9 }
R = { 4, 5, 6, 7, 8 }

Calcula las 10 operaciones:
1. P U Q
2. P ∩ Q
3. P - Q
4. Q - P
5. P'
6. P Δ Q
7. (P U Q) ∩ R
8. P - (Q ∩ R)
9. (P ∩ Q)'
10. (P - R) U (Q - R)

------------------------------------------------------------------------
[SOLUCION Y CHECKPOINT DEL EJERCICIO ESPEJO 4]
------------------------------------------------------------------------
1. P U Q = { 1, 2, 3, 5, 7, 9 }
2. P ∩ Q = { 3, 5, 7 }
3. P - Q = { 2 }
4. Q - P = { 1, 9 }
5. P' = { 1, 4, 6, 8, 9, 10 }
6. P Δ Q = { 1, 2, 9 }
7. (P U Q) ∩ R = { 5, 7 }
8. P - (Q ∩ R) = { 2, 3 }
9. (P ∩ Q)' = { 1, 2, 4, 6, 8, 9, 10 }
10. (P - R) U (Q - R) = { 1, 2, 3, 9 }
