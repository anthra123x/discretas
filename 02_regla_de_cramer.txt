========================================================================
BLOQUE 1: CALCULO DE DETERMINANTES 3x3 (METODO DE SARRUS)
========================================================================

1. ALGORITMO MENTAL DE SARRUS EN 4 PASOS:

Sea el determinante 3x3:
|  a   b   c |
|  d   e   f |
|  g   h   i |

- Paso 1 (Duplicacion): Copias las dos primeras filas exactamente iguales 
  debajo de la tercera fila:
  |  a   b   c |
  |  d   e   f |
  |  g   h   i |
  - - - - - - -
  |  a   b   c |  (fila 1 repetida)
  |  d   e   f |  (fila 2 repetida)

- Paso 2 (Diagonales Principales hacia abajo a la derecha \):
  D1 = a * e * i
  D2 = d * h * c
  D3 = g * b * f
  Suma Principales (P) = D1 + D2 + D3

- Paso 3 (Diagonales Secundarias hacia abajo a la izquierda /):
  D4 = c * e * g
  D5 = f * h * a
  D6 = i * b * d
  Suma Secundarias (S) = D4 + D5 + D6

- Paso 4 (Resta y Regla de Signos):
  Resultado = P - (S)
  ALERTA CRITICA: El signo menos le cambia el signo a todo S. 
  Si S = -6, entonces -(-6) = +6.


2. EJEMPLO MODELO: DETERMINANTE CON SIGNOS MIXTOS
Calcular:
|  1   2  -2 |
|  4  -1   1 |
| -2   1   1 |

Paso 1: Duplicamos filas 1 y 2:
|  1   2  -2 |
|  4  -1   1 |
| -2   1   1 |
--------------
|  1   2  -2 |
|  4  -1   1 |

Paso 2 (Principales \):
- D1 = 1 * (-1) * 1 = -1
- D2 = 4 * 1 * (-2) = -8
- D3 = (-2) * 2 * 1 = -4
P = (-1) + (-8) + (-4) = -13

Paso 3 (Secundarias /):
- D4 = (-2) * (-1) * (-2) = -4  (tres negativos dan negativo)
- D5 = 1 * 1 * 1 = 1
- D6 = 1 * 2 * 4 = 8
S = (-4) + 1 + 8 = 5

Paso 4:
Delta = P - S = -13 - (5) = -18.


3. TU TURNO: EJERCICIO ESPEJO 1
Calcula el siguiente determinante 3x3 aplicando Sarrus:
|  2  -1   3 |
|  1   0   2 |
| -1   4   1 |

------------------------------------------------------------------------
[SOLUCION Y CHECKPOINT DEL EJERCICIO ESPEJO 1]
------------------------------------------------------------------------
Duplicamos filas:
|  2  -1   3 |
|  1   0   2 |
| -1   4   1 |
--------------
|  2  -1   3 |
|  1   0   2 |

Principales (\):
- 2 * 0 * 1 = 0
- 1 * 4 * 3 = 12
- (-1) * (-1) * 2 = 2
P = 0 + 12 + 2 = 14

Secundarias (/):
- 3 * 0 * (-1) = 0
- 2 * 4 * 2 = 16
- 1 * (-1) * 1 = -1
S = 0 + 16 - 1 = 15

Resultado:
Delta = P - S = 14 - (15) = -1.


========================================================================
BLOQUE 2: RESOLUCION COMPLETA DE SISTEMAS 3x3 POR CRAMER
========================================================================

1. ALGORITMO DE CRAMER EN 5 FASES:

- Fase 1: Calcular Delta (con los coeficientes de x, y, z).
  Si Delta = 0 -> Detente: el sistema no tiene solucion unica.
- Fase 2: Calcular Delta x (reemplazando columna de x por los terminos 
  independientes).
- Fase 3: Calcular Delta y (reemplazando columna de y por los terminos 
  independientes).
- Fase 4: Calcular Delta z (reemplazando columna de z por los terminos 
  independientes).
- Fase 5: Divisiones finales:
  x = Delta x / Delta
  y = Delta y / Delta
  z = Delta z / Delta
- Fase 6 (Comprobacion en 30 segundos): Reemplaza (x, y, z) en la primera 
  ecuacion original. Si da exacto, tienes 5.0 garantizado.


2. EJEMPLO MODELO COMPLETO PASO A PASO:
Sistema:
1)   x + 2y - 2z = 10
2)  4x -  y +  z = 4
3) -2x +  y +  z = -2
Terminos independientes: 10, 4, -2.

Paso 1: Delta = -18 (calculado en Bloque 1).

Paso 2: Delta x:
Columna x cambiada por (10, 4, -2):
| 10   2  -2 |
|  4  -1   1 |
| -2   1   1 |
- Principales: 10*(-1)*1 + 4*1*(-2) + (-2)*2*1 = -10 - 8 - 4 = -22
- Secundarias: (-2)*(-1)*(-2) + 1*1*10 + 1*2*4 = -4 + 10 + 8 = 14
- Delta x = -22 - (14) = -36.

Paso 3: Delta y:
Columna y cambiada por (10, 4, -2):
|  1  10  -2 |
|  4   4   1 |
| -2  -2   1 |
- Principales: 1*4*1 + 4*(-2)*(-2) + (-2)*10*1 = 4 + 16 - 20 = 0
- Secundarias: (-2)*4*(-2) + 1*(-2)*1 + 1*10*4 = 16 - 2 + 40 = 54
- Delta y = 0 - (54) = -54.

Paso 4: Delta z:
Columna z cambiada por (10, 4, -2):
|  1   2  10 |
|  4  -1   4 |
| -2   1  -2 |
- Principales: 1*(-1)*(-2) + 4*1*10 + (-2)*2*4 = 2 + 40 - 16 = 26
- Secundarias: 10*(-1)*(-2) + 4*1*1 + (-2)*2*4 = 20 + 4 - 16 = 8
- Delta z = 26 - (8) = 18.

Paso 5: Soluciones:
- x = (-36) / (-18) = 2
- y = (-54) / (-18) = 3
- z = (18) / (-18) = -1

Paso 6: Comprobacion:
x + 2y - 2z = (2) + 2(3) - 2(-1) = 2 + 6 + 2 = 10 (VERIFICADO).


3. TU TURNO: EJERCICIO ESPEJO 2 (¡ALERTA: VARIABLE FALTANTE!)
Resuelve el siguiente sistema aplicando el algoritmo:
1)  x +  y + z = 6
2)      2y - z = 1    (Pista: 0x + 2y - z = 1)
3) 3x -  y + z = 4

------------------------------------------------------------------------
[SOLUCION Y CHECKPOINT DEL EJERCICIO ESPEJO 2]
------------------------------------------------------------------------
Matriz ordenada:
Fila 1:  1,  1,  1 | 6
Fila 2:  0,  2, -1 | 1
Fila 3:  3, -1,  1 | 4

1. Calculo de Delta:
- Principales: 1*2*1 + 0*(-1)*1 + 3*1*(-1) = 2 + 0 - 3 = -1
- Secundarias: 1*2*3 + (-1)*(-1)*1 + 1*1*0 = 6 + 1 + 0 = 7
- Delta = -1 - (7) = -8

2. Calculo de Delta x (columna 1 = 6, 1, 4):
- Principales: 6*2*1 + 1*(-1)*1 + 4*1*(-1) = 12 - 1 - 4 = 7
- Secundarias: 1*2*4 + (-1)*(-1)*6 + 1*1*1 = 8 + 6 + 1 = 15
- Delta x = 7 - (15) = -8

3. Calculo de Delta y (columna 2 = 6, 1, 4):
- Principales: 1*1*1 + 0*4*1 + 3*6*(-1) = 1 + 0 - 18 = -17
- Secundarias: 1*1*3 + (-1)*4*1 + 1*6*0 = 3 - 4 + 0 = -1
- Delta y = -17 - (-1) = -16

4. Calculo de Delta z (columna 3 = 6, 1, 4):
- Principales: 1*2*4 + 0*(-1)*6 + 3*1*1 = 8 + 0 + 3 = 11
- Secundarias: 6*2*3 + 1*(-1)*1 + 4*1*0 = 36 - 1 + 0 = 35
- Delta z = 11 - (35) = -24

5. Soluciones finales:
- x = (-8) / (-8) = 1
- y = (-16) / (-8) = 2
- z = (-24) / (-8) = 3

6. Comprobacion:
- Ec 1: 1 + 2 + 3 = 6 (Correcto)
- Ec 2: 2(2) - 3 = 1 (Correcto)
- Ec 3: 3(1) - 2 + 3 = 4 (Correcto)


========================================================================
BLOQUE 3: PROTOCOLO ANTE TRAMPAS DE PARCIAL
========================================================================

1. Variable faltante: Si falta una letra en una ecuacion, su coeficiente 
   es CERO (0). En la matriz pones 0 en esa posicion.
2. Ecuacion desordenada: Ordena siempre en formato x, y, z = termino independiente 
   antes de vaciar numeros a la matriz.
3. Delta = 0: Si Delta da cero, no se puede dividir entre cero. El sistema 
   no tiene solucion unica mediante Cramer.
